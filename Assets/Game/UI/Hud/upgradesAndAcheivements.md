What the player sees
Upgrade picked up:

The bottom-center text area briefly shows a monospace string (e.g., "STAMINA +20%" or "SIGNAL AMPLIFIED") for 2 seconds, then vanishes. No icon, no popup, no sound cue (unless you add one). If a typewriter line was active, it stops, the code fragment appears, then the typewriter resumes.

It reads like M7's optics logging a system change. The player learns "something got better" without being told.

Achievement unlocked:

Nothing. No text. No flash. No bar change. No sound.

The player only knows when the next objective's guidance line appears via typewriter. The shift in what the text says is the only signal that progress happened. If the previous line was "find the signal source" and the next is "the door is open" — the player infers they did the right thing.

The contrast is the design:

Event	Feedback	Why
Upgrade	Code fragment (2s)	Mechanical. A system changed. You need to know what changed to play correctly.
Achievement	Nothing	Emotional. You're not being rewarded. You're surviving. The silence is the reward.

A player who's been playing for 20 minutes will notice: "I found an orb and the screen flickered with text" vs. "I did that thing and... nothing happened, but the next line was different." The second one is more unsettling than any achievement banner could be.
